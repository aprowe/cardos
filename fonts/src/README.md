Source fonts for `fonts/fonts.txt`, both under the SIL Open Font License 1.1
(the licence texts are beside them), from github.com/google/fonts:

- Inter (variable; the numbers use its Bold) -- Rasmus Andersson
- Space Mono Bold -- Colophon Foundry (no longer used; kept for comparison)
- Atkinson Hyperlegible Regular and Bold -- Braille Institute of America

The .cfnt files built from them are bitmaps of these fonts and carry the
same licence.
